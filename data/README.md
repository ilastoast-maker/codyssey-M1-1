# Data

- `raw/tsmc_2330_tw_2021_2025.csv`: TWSE `STOCK_DAY` 월별 응답을 일별 CSV로 결합한 원본
- `processed/tsmc_features.csv`: 이동평균·수익률·변동성·이상치·시장 국면을 추가한 분석 데이터
- `processed/metrics.json`: REPORT.md에 사용한 핵심 수치

출처: Taiwan Stock Exchange Corporation(TWSE). 데이터 재사용·배포 시 TWSE 이용약관과 출처 표시 조건을 확인한다. 휴장일은 결측치로 보간하지 않는다.
